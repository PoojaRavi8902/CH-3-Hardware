3.1 Central Processing Unit (CPU) Architecture

Topic: The Von Neumann Model and the Fetch-Execute Cycle

3.1.1 The Von Neumann Model

Named after polymath John von Neumann, this architecture is the foundation of almost all modern computers. The key concept is the Stored Program Concept: instructions and data are stored in the same memory (RAM) as binary values.

Key Components of the CPU:

Component Sub-Sub Topic: Detailed Functionality
Arithmetic Logic Unit (ALU) Performs all mathematical calculations (+, -, *, /) and logical operations (AND, OR, NOT) and comparisons (<, >, ==).
Control Unit (CU) The "manager." It decodes instructions and sends control signals to coordinate how data moves around the CPU and between the CPU and memory.
System Clock Produces continuous pulses. The "Clock Speed" (measured in Hz) determines how many Fetch-Execute cycles can happen per second.

3.1.2 Registers

Registers are high-speed storage locations internal to the CPU. They hold data currently being processed.

  • Program Counter (PC): Holds the address of the next instruction to be fetched.
  • Memory Address Register (MAR): Holds the address of the memory location currently being read from or written to.
  • Memory Data Register (MDR): Holds the actual data/instruction just fetched from memory or waiting to be written to memory.
  • Current Instruction Register (CIR): Holds the instruction that is currently being decoded and executed.
  • Accumulator (ACC): Stores the immediate results of calculations performed by the ALU.

3.1.3 The Fetch-Execute Cycle

This is the continuous process of the CPU. Here is the overwhelming detail of each step:

1. FETCH: The address in the PC is copied to the MAR. The PC is incremented. The instruction at the MAR address is moved to the MDR via the data bus, then copied to the CIR.

2. DECODE: The Control Unit interprets the instruction in the CIR to see what needs to be done.

3. EXECUTE: The instruction is carried out. If a calculation is needed, the ALU is used and results are stored in the ACC.
