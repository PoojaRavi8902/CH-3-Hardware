3.3 Data Storage

Primary, Secondary, and Offline storage technologies.

3.3.1 Storage Hierarchy

Computers use a hierarchy of storage to balance speed, cost, and capacity.

  • Primary Storage: Directly accessible by the CPU (RAM, ROM). Fastest access.
  • Secondary Storage: Non-volatile storage for files and OS (HDD, SSD). Large capacity.
  • Offline Storage: Removable storage used for transport or backup (USB Flash, Optical Disks).

3.3.2 Primary Memory: RAM vs ROM

RAM (Random Access Memory)

Volatile memory that stores data currently in use. DRAM needs refreshing; SRAM is faster and used for Cache.

ROM (Read Only Memory)

Non-volatile memory. Stores start-up instructions (BIOS/Bootstrap). Data cannot be easily changed.

3.3.3 Secondary Storage Types

Magnetic (HDD): Uses magnetized platters and read/write heads. High capacity but slow due to moving parts.

Solid State (SSD): Uses NAND flash gates. No moving parts, silent, and much faster than HDD, but more expensive per GB.

Optical Storage Comparison

Data is stored in "Pits" and "Lands" read by lasers. The wavelength of the laser determines capacity:

Format Laser Type Typical Capacity
CD-ROM Red Laser (Long wave) 700 MB
DVD-ROM Red Laser (Short wave) 4.7 GB
Blu-ray Blue/Violet Laser 25 GB - 50 GB

3.3.4 Cloud vs Local Storage

Cloud Storage: Data is stored on remote servers accessed via the internet.

  • ✅ Pros: Access from any device, easy sharing, automatic backups.
  • ❌ Cons: Requires internet, monthly subscription costs, security concerns.
