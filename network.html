3.4 Network Hardware

Devices and media that connect the world.

3.4.1 The Hardware of Connectivity

To connect to a network (LAN or WAN), specific hardware is required to manage data packets and physical connections.

  • NIC (Network Interface Card): An internal hardware component that allows a device to connect to a network. It contains the hard-coded MAC Address.
  • Router: Forwards data packets between different networks by reading the IP Address. It creates a "routing table" to find the quickest path for data.
  • Switch: Connects devices within a LAN. Unlike a Hub, it checks the destination MAC address and sends data only to the specific intended recipient.

3.4.2 MAC vs IP Addresses

MAC Address

Physical Address: Unique ID assigned by the manufacturer. Written in Hexadecimal (e.g., 00:1A:2B:3C:4D:5E). It never changes.

IP Address

Logical Address: Assigned by the network router. Identifies a device's location on the internet. Can be IPv4 (32-bit) or IPv6 (128-bit).

3.4.3 Transmission Media

Medium Method Pros/Cons
Copper (Ethernet) Electrical pulses ✅ Cheap. ❌ Signal degrades over distance.
Fibre Optic Pulses of light ✅ Massive bandwidth, no interference. ❌ Expensive.
Wi-Fi Radio waves ✅ High mobility. ❌ Security risks, lower speed.
