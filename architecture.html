3.1 Central Processing Unit (CPU) Architecture

Topic: The Von Neumann Model and the Fetch-Execute Cycle

3.1.1 The Von Neumann Model

Named after John von Neumann, this architecture describes a system where instructions and data are stored in the same memory (RAM) as binary values.

Key Components and Buses

The CPU communicates with RAM via three System Buses:

  • Address Bus: Unidirectional. Carries addresses from the CPU to RAM.
  • Data Bus: Bidirectional. Carries actual data/instructions between the CPU and RAM.
  • Control Bus: Bidirectional. Carries command signals (like Read/Write).

3.1.2 Specialized Registers

Registers are small, extremely fast storage locations within the CPU.

  • PC (Program Counter): Holds the address of the next instruction.
  • MAR (Memory Address Register): Holds the address of the current memory location being accessed.
  • MDR (Memory Data Register): Holds the data just fetched or about to be stored.
  • CIR (Current Instruction Register): Holds the instruction being decoded.
  • ACC (Accumulator): Stores results of logic and math operations.

3.1.3 The Fetch-Execute Cycle

This is the continuous process of the CPU. Here is the visual breakdown of the cycle:

1. FETCH: The address in the PC is copied to the MAR. The PC is incremented. The instruction at the MAR address is moved to the MDR, then copied to the CIR.

2. DECODE: The Control Unit interprets the instruction in the CIR.

3. EXECUTE: The instruction is carried out (ALU used for calculations).

3.1.4 Factors Affecting CPU Performance

A CPU's speed is determined by three main "Performance Pillars":

System Clock Speed

Measured in GHz. Higher clock speed means more Fetch-Execute cycles per second.

Number of Cores

More cores allow the CPU to process multiple instructions simultaneously (Parallel Processing).

Cache Size

Larger cache reduces the time the CPU spends waiting for data to arrive from RAM.
